## 🚀 Quickstart

```sh
npm install       # Install dependencies
npm run dev       # Start local dev server at localhost:4324
npm run build     # Build production site to ./dist/
npm run preview   # Preview production build locally
```

## 📁 Project Structure

```
/src
  ├── data/content.ts      # All portfolio data (projects, credentials, stats, resume variants)
  ├── pages/               # Astro pages (index, about, contact, blog, services, resume)

  └── components/          # Theme toggle, newsletter, UI components
/public/

```
